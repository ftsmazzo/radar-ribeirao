# Regras do projeto

- Repositório privado. Notas e transcrições não viram matéria sem revisão humana.
- Não gravar `OPENROUTER_API_KEY`, `APP_PASSWORD` ou `DATABASE_URL` no git.
- Carimbo fechado só com URL `https` ou fato da base oficial com `source_url` https.
- Não rotular frase como fake. Mostrar estado, fonte e necessidade de resposta.
- A demo de programa fictício deve estar marcada como simulação de escuta.
- Banco deste projeto é exclusivo. Não apontar `DATABASE_URL` para outro serviço.
- Notificação da demo grava na sala de imprensa do app. Integração WhatsApp/e-mail vem depois.
